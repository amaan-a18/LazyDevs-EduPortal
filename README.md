# 🌟 **LazyDevs Study Portal**
A lightweight, modular, and beginner-friendly **web-based study platform** built using **HTML, CSS, PHP, and MySQL**.

> 🎓 Perfect for learning web development fundamentals  
> 📘 Includes tutorials, authentication, and study modules  
> ⚡ Fast • Clean • Easy to customize   

---

## 🚀 **Features**
✨ **User Authentication** – Login & logout system  
🎨 **HTML, CSS & PHP Tutorials** – Simple & structured learning pages  
📄 **Downloadable Study Materials** – PDFs & notes  
📝 **Form Handling Examples** – Learn POST/GET with real demos  
💡 **Minimal & Clean UI** – Lightweight and beginner-friendly  

---

## 🧩 **Setup Guide**

### 1️⃣ **Import the MySQL Database**
- Open **phpMyAdmin**
- Create a new database (e.g., `lazydevs`)
- Import the provided `.sql` file

### 2️⃣ **Configure Database**
Edit `db.php`:
```php
$servername = "localhost";
$username   = "root";
$password   = "";
$dbname     = "lazydevs"; 
```

### 3️⃣ **Run Using Local Server**
- Start **Apache** and **MySQL** in XAMPP/WAMP  
- Place this project folder inside `htdocs` or `www`

### 4️⃣ **Open in Browser**
👉 **http://localhost/LazyDevs-EduPortal/**
